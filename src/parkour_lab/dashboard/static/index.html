About this dashboard

AI Parkour Lab trains a 25-DoF articulated MuJoCo humanoid on 22 fixed parkour courses (20 training, 2 held-out) with PPO, parallel CPU environments and an adaptive curriculum. This dashboard reads the immutable run directories written by the trainer.

What is real here

  • All metrics come from saved run records (metrics/*.csv, metrics/episodes.jsonl, evaluation/*.json).
  • 3D replays are recorded body poses from actual MuJoCo episodes, replayed in the browser.
  • Training is launched as a separate local process with validated parameters.

What this dashboard does not do

  • It does not run the physics engine or the learning algorithm in the browser.
  • It does not modify checkpoints, levels or policy weights.
  • It does not claim a learned parkour behaviour that the saved evaluations do not show.

CLI equivalents

parkour list-levels
parkour train --all --steps 1000000 --envs 4 --run-id adaptive-01
parkour evaluate --checkpoint runs/adaptive-01/checkpoints/best.npz --all
parkour watch --checkpoint runs/adaptive-01/checkpoints/best.npz --level level-03-small-hops
parkour benchmark --envs 1,2,4 --steps 300
